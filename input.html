MATLAB 프로그래밍

계산기처럼 쓰는 법에서 시작해 배열, 함수, 반복문까지. 코드를 치면 무엇이 나오는지 바로 말할 수 있게 정리했어요.

  • 배열 · 함수 · 프로그래밍

1장 · MATLAB 개요

  • 연산 순서는 괄호 → 거듭제곱 → 곱셈·나눗셈 → 덧셈·뺄셈이고, 같은 순위는 왼쪽부터 계산해요. \는 왼쪽 나눗셈이라 2\7은 7/2예요.
  • 지수에 분수를 쓸 땐 괄호가 꼭 필요해요. 27^(1/3)은 3이지만 27^1/3은 9예요.
  • 줄 끝 세미콜론은 출력만 숨기고 계산은 해요. 변수에 담지 않은 결과는 ans에 남아요.
  • 변수 이름은 영문자로 시작하고 영문자·숫자·밑줄만 써요. 대소문자를 구분해요.
  • Inf(1/0), NaN(0/0), eps(1과 그다음 수 사이 간격, 2.2204e-16). format은 보이는 자릿수만 바꾸고 저장된 값은 그대로예요.
  • i, j는 허수 단위예요. 7/2i는 7/(2i)라서 −3.5i가 돼요.
x = 0:0.1:5;
plot(x, 2*sqrt(x), '+'); hold on
plot(x, 4*sin(3*x), 'o-')
legend('y', 'z')   % 그린 순서대로 이름이 붙어요

2장 · 배열 · 셀 · 구조체

  • a:q:b는 b를 넘지 않을 때까지 만들어요(0:2:7 → 0 2 4 6). linspace(a,b,n)은 양 끝을 포함해 n개를 고르게 나눠요.
  • 배열끼리 곱하기·나누기·거듭제곱은 점을 붙인 원소별 연산 .* ./ .^이에요. 덧셈·뺄셈은 원래 원소별이라 점이 없어요.
  • A(행, 열)로 꺼내고, 콜론은 "전부"예요. A(:)는 열 순서로 쌓은 열 벡터이고, 이 열 순서 번호가 find에도 그대로 쓰여요.
  • 행렬 함수는 기본적으로 열마다 계산해요. max(A)는 열마다 최댓값, max(A,[],2)는 행마다예요. size는 (행, 열), length는 둘 중 큰 값, numel은 전체 개수예요.
  • A*B는 행렬 곱이라 왼쪽 열 수 = 오른쪽 행 수여야 해요. 연립방정식 Ax = b는 x = A\b로 풀어요(b는 열 벡터).
  • 다항식은 최고차항부터 계수를 써요. roots(근), poly(근 → 계수), conv(곱), deconv(나눗셈), polyval(값).
  • norm은 벡터 길이, dot은 내적(0이면 수직), cross는 두 벡터에 수직인 벡터예요. 셀 배열은 {}, 구조체는 s.field로 다뤄요.
A = [6 12 4; 7 -2 3; 2 8 -9];
b = [70; 5; 64];
x = A\b      % 3; 5; -2

3장 · 함수

  • 반올림 방향: round는 가장 가까운 정수, ceil은 +∞ 쪽, floor는 −∞ 쪽, fix는 0 쪽. 음수에서 floor와 fix가 갈려요.
  • log는 자연로그, 상용로그는 log10이에요. 삼각함수는 라디안이고, 도 단위는 sind, cosd를 써요.
  • 함수 파일은 첫 줄이 function [출력] = 이름(입력)이고, 파일 이름과 함수 이름이 같아야 해요. 함수는 바깥 변수를 보지 못해요.
  • 함수를 다른 함수에 넘길 땐 함수 핸들 @를 써요. fplot(@cos, [0 2*pi]), fzero(@cos, 2), fminbnd(@cos, 0, 4).
  • 익명 함수 f = @(x) x.^2는 파일 없이 만드는 함수예요. 이미 핸들이라 넘길 때 @를 다시 붙이지 않아요.
function [A, C] = circle(r)
  A = pi*r.^2;
  C = 2*pi*r;
end

poly1 = @(x) 4*x.^2 - 50*x + 5;
[x, y] = fminbnd(poly1, -10, 10)   % x = 6.25

4장 · 프로그래밍

  • 논리값은 0만 거짓이고 나머지는 모두 참이에요. 같음은 ==, 같지 않음은 ~=예요.
  • 우선순위는 괄호 → ^ → ~ → 산술 → 관계 → & → |. 그래서 5 > 2 + 7은 0, (5 > 2) + 7은 8이에요.
  • 논리 인덱싱 A(A > 3)은 조건에 맞는 값을, find(A > 3)는 그 위치(열 순서 번호)를 줘요.
  • if의 조건이 배열이면 모든 원소가 참일 때만 참이에요. 위에서부터 처음 참인 블록 하나만 실행돼요.
  • for k = 1:n이 끝나도 k는 마지막 값으로 남아요. 합은 0, 곱은 1에서 시작해요.
  • break는 반복을 끝내고, continue는 이번 반복만 건너뛰어요. while은 매 반복 시작 전에 조건을 검사해요.
total = 0;
for k = 1:15
    total = 5*k^2 - 2*k + total;
end
total          % 5960

C 프로그래밍

코드를 머릿속에서 한 줄씩 실행해 보는 연습이 중심이었어요. 자주 헷갈렸던 규칙을 장별로 모았어요.

  • Perfect C 2–7장
  • 자료형 · 입출력 · 연산자
  • 조건 · 반복

2장 · C 프로그래밍 첫걸음

  • C는 대소문자를 구분해요. 프로그램은 소문자 main에서 시작해요.
  • 문자열은 큰따옴표로 감싸고, 문장은 세미콜론으로 끝내요. 세미콜론이 빠지면 오류가 다음 줄에서 보고되기도 해요.
  • printf를 쓰려면 #include <stdio.h>가 필요해요.

3장 · 자료형과 변수

  • 0으로 시작하면 8진수, 0x로 시작하면 16진수예요. 010은 8, 0x1A는 26이에요.
  • int에 3.9를 넣으면 소수점 아래가 버려져 3이 돼요(반올림 아님).
  • 정수끼리 나누면 몫만 남아요. 7 / 2는 3이고, 3.5를 얻으려면 7.0 / 2처럼 한쪽을 실수로 만들어요.
  • 문자는 사실 정수(아스키 코드)예요. 'A'는 65라서 'A' + 2는 'C'예요. 'A'는 문자 하나, "A"는 문자열이에요.

4장 · 전처리와 입출력

  • %5d는 5칸 오른쪽 정렬, %-5d는 왼쪽 정렬, %05d는 빈칸을 0으로 채워요. %7.3f는 소수 셋째 자리까지 만든 뒤 전체 7칸에 맞춰요.
  • scanf에는 값이 아니라 주소를 넘겨요: scanf("%d", &n).
  • double을 읽을 땐 scanf에서 %lf를 써요. printf는 %f로 충분해요.

5장 · 연산자

  • a++는 지금 값을 넘긴 뒤 증가하고, ++a는 먼저 증가한 값을 넘겨요.
  • /는 몫, %는 나머지예요. (double)a / b는 실수 나눗셈이지만 (double)(a / b)는 이미 잘린 몫을 바꾼 거예요.
  • &&, ||는 단락 평가를 해요. 왼쪽만으로 결과가 정해지면 오른쪽(예: b++)은 실행되지 않아요.
  • 비트 연산: & | ^는 비트마다, ~x는 항상 −x − 1, x << n은 2ⁿ을 곱한 것과 같아요.
  • 10 <= a <= 19는 범위 검사가 아니에요. 왼쪽부터 0 또는 1이 되니 a >= 10 && a <= 19로 써요.

6장 · 조건

  • if (x = 5)는 비교가 아니라 대입이라 항상 참이에요. 비교는 ==예요.
  • if (조건);처럼 세미콜론을 붙이면 빈 문장이 되어, 아래 문장은 조건과 상관없이 실행돼요.
  • else는 가장 가까운 if와 짝이에요. 들여쓰기는 의미가 없어요.
  • switch는 break를 만날 때까지 아래 case로 흘러가요(fall-through). default는 위치가 자유롭지만 하나만 둘 수 있어요.
  • case 뒤에는 정수·문자 상수만 와요. 실수(2.5), 문자열("B"), 변수, 같은 값의 중복은 컴파일 오류예요. switch 괄호 안도 정수형이어야 해요.
switch (score / 10) {
case 10:
case 9: printf("A\n"); break;   /* 10과 9를 묶음 */
case 8: printf("B\n"); break;
default: printf("F\n");
}

7장 · 반복

  • do { } while (조건);은 본문을 먼저 실행해서 최소 한 번은 돌아요. 끝의 세미콜론이 필요한 건 do-while뿐이에요.
  • for (...);처럼 세미콜론을 붙이면 빈 문장을 반복하고, 아래 블록은 반복 밖에서 한 번만 실행돼요.
  • continue는 for에서는 증감식으로, while에서는 조건식으로 가요.
  • break는 가장 안쪽의 반복문이나 switch 하나만 빠져나와요. switch 안의 break로는 바깥 반복이 끝나지 않아요.
  • 누적 변수는 "몇 번 0으로 돌아가야 하나"로 초기화 위치를 정해요. 합은 0, 곱은 1에서 시작해요.
  • while (n-- > 2)는 비교한 뒤 줄이니, 마지막 비교가 거짓이어도 한 번 더 줄어요.

6장 · 열화학 (6.1–6.4)

에너지와 열역학 제1법칙
  • 관심 있는 부분이 계, 나머지가 주위예요. 에너지는 열(q)이나 일(w)로 오가고, 둘 다 계 기준으로 부호를 정해요: 계로 들어오면 +, 나가면 −.
  • 제1법칙: ΔU = q + w. 우주 전체 에너지는 보존되고, 계의 내부 에너지 변화는 받은 열과 받은 일의 합이에요.
  • 압력에 대한 일 w = −P_ext·ΔV. 팽창(ΔV > 0)하면 계가 일을 하니 w < 0, 압축(ΔV < 0)되면 w > 0. 부피가 줄었는데 w를 음수로 쓰는 게 가장 흔한 실수예요(1 L·atm = 101.3 J).
  • 상태 함수는 출발점과 도착점만으로 정해지고 경로와 무관해요(U, H, P, V, T). q와 w는 경로에 따라 달라서 상태 함수가 아니지만, 그 합 ΔU는 상태 함수예요.
엔탈피 ΔH와 ΔU
  • H = U + PV. 일정 압력에서 일이 PV 일뿐이면 ΔH = q_p, 즉 일정 압력에서 오간 열이 엔탈피 변화예요. ΔH < 0이면 발열, > 0이면 흡열.
  • 이상기체면 PΔV = Δn_g·RT라서 ΔH = ΔU + Δn_g·RT. Δn_g는 (기체 생성물 몰수) − (기체 반응물 몰수)이고, 고체·액체·수용액은 세지 않아요.
  • Δn_g > 0이면 ΔH > ΔU, = 0이면 같고, < 0이면 ΔH < ΔU. 예: N₂(g) + 3H₂(g) → 2NH₃(g)은 Δn_g = −2라 298 K에서 ΔH − ΔU = −2 × 2.48 kJ = −4.96 kJ. HCl(aq) + NaOH(aq) → NaCl(aq) + H₂O(l)처럼 기체가 없으면 ΔH = ΔU예요.
열량 측정
  • 비열 s는 1 g을 1 °C 올리는 열, 열용량 C는 물체 전체를 1 °C 올리는 열이에요: q = m·s·ΔT, q = C·ΔT(ΔT = 나중 − 처음). 물의 비열은 4.184 J/(g·°C).
  • 반응이 낸 열은 열량계(용액)가 모두 받는다고 봐요: q_rxn = −q_열량계. 용액 온도가 오르면 q_용액 > 0, q_rxn < 0이라 발열이에요.
  • 커피컵 열량계는 일정 압력이라 q_p = ΔH. 섞은 용액의 질량은 두 용액의 합이에요. 강산–강염기 중화열은 약 −57 kJ/mol(H⁺ + OH⁻ → H₂O)로 거의 일정해요.
  • 통 열량계(bomb)는 일정 부피라 w = 0, q_v = ΔU예요. ΔH로 바꾸려면 Δn_g·RT를 더해요. "통 = 정적 = ΔU, 커피컵 = 정압 = ΔH"로 짝지어 기억하면 돼요.
  • 측정값은 시료 전체에 대한 열이라, 마지막에 몰수로 나눠 1 mol당으로 바꿔요.
Hess 법칙과 표준 생성 엔탈피
  • 엔탈피는 상태 함수라 반응을 여러 단계로 나눠도 ΔH의 합은 같아요(Hess 법칙). 반응을 뒤집으면 ΔH의 부호가 바뀌고, n배 하면 ΔH도 n배예요.
  • 예: C(s) + 2H₂(g) → CH₄(g)는 [C 연소] + 2 × [H₂ 연소] − [CH₄ 연소] = −393.5 + 2(−285.8) − (−890.3) = −74.8 kJ로, CH₄의 표준 생성 엔탈피와 같아요.
  • 표준 생성 엔탈피 ΔH°f: 표준 상태의 원소로부터 화합물 1 mol을 만들 때의 ΔH. 가장 안정한 형태의 원소(O₂, H₂, N₂, C(흑연))는 0이에요.
  • ΔH°rxn = Σ n·ΔH°f(생성물) − Σ m·ΔH°f(반응물). 계수를 꼭 곱하고, H₂O(l) −285.8과 H₂O(g) −241.8처럼 상태를 확인해요.
  • 결합 엔탈피로 어림하기: 끊는 데는 에너지가 들고(+) 만들 때 나와요(−). ΔH ≈ Σ(끊는 결합) − Σ(만드는 결합)이고, 반응 앞뒤로 그대로 남는 결합은 세지 않아요. 생성 엔탈피 식과 빼는 순서가 반대예요.

7장 · 원자 구조와 주기성

빛과 수소 원자
  • 빛은 c = λν를 만족하는 파동이면서, 에너지 E = hν = hc/λ인 광자의 흐름이에요(h = 6.626 × 10⁻³⁴ J·s). 파장이 짧을수록 광자 에너지가 커요.
  • 수소 원자의 에너지 E_n = −2.178 × 10⁻¹⁸ J / n². 전이에서 나오는 빛은 ΔE = 2.178 × 10⁻¹⁸ J × (1/n_f² − 1/n_i²), λ = hc/ΔE.
  • 준위 간격은 고르지 않아요. n이 커질수록 간격이 좁아져서, Δn이 같아도 아래쪽 전이일수록 ΔE가 커요. 4 → 2는 486 nm(가시광선, Balmer)인데 3 → 1은 103 nm(자외선, Lyman)예요.
  • 광자 수 = 총에너지 / 광자 1개의 에너지. 물질파 λ = h/mv와 불확정성 원리 때문에 전자의 위치는 확률(오비탈)로만 말할 수 있어요.
양자수와 오비탈
  • 규칙은 종속 관계예요: n이 정해지면 l은 0 ~ n − 1, l이 정해지면 m_l은 −l ~ +l, m_s는 항상 ±½. 예를 들어 (3, 3, 0, +½)는 l ≤ n − 1 위반, (2, 0, 1, −½)는 l = 0인데 m_l = 1이라 위반, (1, 0, 0, 0)은 m_s = 0이라 위반이에요.
  • 껍질의 최대 전자 수는 2n²(n = 4면 32), 부껍질은 2(2l + 1)(3d면 10)이에요. 껍질과 부껍질을 구분해서 답해요.
  • 오비탈의 마디 수는 n − 1(그중 l개가 각마디)이에요. 2s는 구형 마디 1개, 2p는 핵을 지나는 평면 마디 1개.

전자 배치와 자기성
  • 파울리 배타 원리(오비탈당 반대 스핀 2개), 쌓음 원리(낮은 에너지부터, 4s가 3d보다 먼저), Hund 규칙(같은 에너지 오비탈에 먼저 하나씩 같은 스핀)으로 채워요.
  • 변칙 배치: 4s와 3d 에너지가 거의 같아서 반쯤 찬 d⁵나 꽉 찬 d¹⁰이 더 안정하면 전자 하나가 3d로 옮겨 가요. Cr [Ar]4s¹3d⁵, Cu [Ar]4s¹3d¹⁰.
  • 양이온은 4s 전자부터 잃어요. 채울 때는 4s가 먼저지만, 채워진 뒤에는 4s가 더 바깥이라 먼저 빠져요. Fe³⁺ = [Ar]3d⁵, Mn²⁺ = [Ar]3d⁵(둘은 등전자), Cu⁺ = [Ar]3d¹⁰.
  • 홀전자가 하나라도 있으면 상자기성(자기장에 끌림), 모두 짝을 지으면 반자기성(살짝 밀림)이에요. Cr은 홀전자 6개, Cu⁺는 0개예요.
주기적 경향
  • 같은 주기에서 오른쪽으로 갈수록 유효 핵전하가 커져 원자 반지름은 작아지고 이온화 에너지는 커져요. 같은 족에서 아래로 가면 껍질이 늘어 반지름이 커지고 이온화 에너지는 작아져요.
  • 두 군데 예외: Be > B (B는 2s보다 에너지가 높고 더 가려진 2p 전자 하나를 떼서 쉬움), N > O (O는 2p⁴에서 한 오비탈에 짝지은 전자가 생겨 반발로 떼기 쉬움).
  • 등전자 이온은 전자 수가 같으니 핵전하가 클수록 작아요: O²⁻ > F⁻ > Na⁺ > Mg²⁺(모두 전자 10개). 음이온 > 중성 원자 > 양이온도 같은 이유예요.
  • 전자 친화도는 전자를 받을 때 나오는 에너지로, 할로젠이 크고 2족과 비활성 기체는 작아요.

8장 · 화학 결합과 분자 구조

결합의 종류와 극성
  • 이온 결합은 전자 이동, 공유 결합은 전자 공유예요. 실제 결합은 전기음성도 차이에 따라 그 사이 어딘가에 있고, 차이가 있으면 극성 공유 결합(δ+, δ−)이 돼요.
  • 분자의 극성은 결합 쌍극자의 벡터 합이에요. 결합이 극성이어도 모양이 대칭이면 상쇄돼 비극성이에요(CO₂, BF₃, CCl₄, XeF₄). "극성 결합이 있으니 극성 분자"는 틀린 추론이에요.
격자 에너지와 Born–Haber 순환
  • 격자 에너지는 기체 이온이 모여 이온 고체가 될 때의 에너지로, U ∝ Q₁Q₂/r이에요. 전하의 곱이 거리보다 훨씬 크게 작용해요.
  • 그래서 MgO(+2, −2) ≫ NaF > NaCl > KCl 순이에요. 전하가 같으면 이온이 작을수록(r이 작을수록) 커요.
  • Born–Haber 순환은 이온 고체 생성의 Hess 법칙이에요: 원소 → 기체 원자 → 기체 이온 → 고체. 승화·이온화·해리는 흡열(+), 전자 친화도와 격자 형성은 발열(−)이고, Cl₂는 원자 하나만 필요하니 ½D예요.
Lewis 구조와 형식 전하
  • 그리는 순서: ① 원자가 전자를 모두 센다(음이온은 전하만큼 더하고 양이온은 뺀다). ② 중심 원자(보통 전기음성도가 가장 작은 원자, H는 절대 중심 아님)에 나머지를 단일 결합으로 잇는다. ③ 바깥 원자부터 옥텟을 채운다. ④ 남은 전자는 중심 원자에. ⑤ 중심이 옥텟에 모자라면 비공유 전자쌍을 끌어와 다중 결합을 만든다.
  • 옥텟 예외: B는 6개로 안정할 수 있고(BF₃), 3주기 이후 원자는 d 오비탈 덕분에 8개를 넘을 수 있어요(PCl₅ 10개, SF₆ 12개, XeF₄ 12개).
  • 형식 전하 = 족 전자 − 비공유 전자 − ½ × 공유 전자. 형식 전하의 합은 분자나 이온의 전하와 같아요. 가장 그럴듯한 구조는 형식 전하가 0에 가깝고, 음의 형식 전하가 전기음성도 큰 원자에 있는 구조예요.

9장 · 혼성 오비탈과 분자 오비탈

혼성 오비탈과 σ · π 결합
  • 중심 원자의 전자 영역 수가 혼성을 정해요: 2 → sp, 3 → sp², 4 → sp³, 5 → sp³d, 6 → sp³d². 비공유 전자쌍도 혼성 오비탈 하나를 차지해요(NH₃의 N은 sp³).
  • σ 결합은 혼성 오비탈끼리(또는 혼성 오비탈과 H의 1s)가 축을 따라 정면으로 겹친 결합이에요. π 결합은 혼성에 쓰이지 않고 남은 p 오비탈끼리 옆으로 겹친 결합이에요. π 결합을 "sp²–sp² 겹침"이라고 쓰면 틀려요.
  • 단일 결합 σ 1, 이중 결합 σ 1 + π 1, 삼중 결합 σ 1 + π 2. 예: C₂H₄는 σ 5 + π 1(각 C가 sp²), C₂H₂는 σ 3 + π 2(각 C가 sp), HCN은 σ 2 + π 2(C와 N 모두 sp).
  • 결합을 표로 쓸 때는 "C(sp²)–H(1s) σ", "C(2p)–C(2p) π"처럼 어느 오비탈끼리 겹쳤는지까지 적어요.
분자 오비탈(MO) 모형
  • 원자 오비탈이 분자 전체에 걸친 분자 오비탈로 합쳐진다고 봐요. 파동이 보강 간섭하면 두 핵 사이 전자 밀도가 커진 결합성 MO(원래보다 낮은 에너지), 상쇄 간섭하면 핵 사이에 마디가 생긴 반결합성 MO(더 높은 에너지)가 돼요.
  • Lewis 구조로는 설명할 수 없는 홀전자 분자와 자기적 성질을 설명해요. 대표적인 예가 액체 산소가 자석에 끌리는 상자기성이에요.
  • 규칙: ① 만들어진 MO 수 = 섞인 원자 오비탈 수. ② 결합성 MO가 더 안정할수록 반결합성 MO는 더 불안정. ③ 낮은 에너지부터 채움. ④ MO 하나에 전자 2개까지. ⑤ 같은 에너지면 Hund 규칙. ⑥ 전자 수 = 두 원자의 전자 합.
  • 결합 차수 = (결합성 전자 − 반결합성 전자) / 2. 클수록 결합이 강하고 짧아요. 0이면 분자가 생기지 않아요: H₂ 1, H₂⁺ ½, He₂ 0, Li₂ 1, Be₂ 0.
  • 원자가 오비탈만 MO에 기여해요. Li의 1s는 2s보다 훨씬 작아 서로 겹치지 않아요.
2주기 동핵 이원자 분자
  • 2p끼리 정면으로 겹치면 σ2p와 σ*2p, 옆으로 겹치면 π2p 두 개와 π*2p 두 개가 생겨요.
  • 순서가 N₂까지와 O₂부터 달라요. B₂, C₂, N₂는 2s–2p 섞임이 커서 π2p가 σ2p보다 낮고, O₂, F₂는 σ2p가 π2p보다 낮아요. B₂가 상자기성이라는 실험 결과가 π2p가 아래라는 증거예요.
  • O₂는 π*2p 두 개에 전자가 하나씩(Hund) 들어가 홀전자 2개, 상자기성이에요. Lewis 구조로는 모든 전자가 짝지어 보여서 설명할 수 없어요.
  • 이온의 결합 차수: 반결합 전자를 빼면 결합이 강해지고(O₂⁺ 2.5 > O₂ 2), 결합 전자를 빼거나 반결합 전자를 더하면 약해져요. N₂⁺와 N₂⁻는 결합 차수가 2.5로 같지만, 앞은 결합성 σ2p 전자를 뺐고 뒤는 반결합성 π*2p에 전자를 더한 결과예요. N₂의 가장 높은 채워진 오비탈(HOMO)은 σ2p예요.

10장 · 액체와 고체

  • 분자간 힘은 분산력 < 쌍극자–쌍극자 < 수소결합 순이에요. 단, 분자량이 비슷할 때의 비교예요. 수소결합은 H가 N, O, F에 직접 붙어 있을 때만 생겨요.
  • 분자간 힘이 클수록 끓는점·표면장력·점성은 커지고 증기압은 작아져요. 끓는점은 증기압이 외부 압력과 같아지는 온도예요.
  • Clausius–Clapeyron 식 ln(P₁/P₂) = (ΔH_vap/R)(1/T₂ − 1/T₁)로 두 온도의 증기압을 이어요. T는 K, ΔH는 J/mol로 맞춰요.
  • 물은 얼음이 액체보다 밀도가 작아서 상평형 그림의 고체–액체 선 기울기가 음수예요. CO₂는 양수이고, 1 atm에서 승화해요.
  • 결정성 고체는 금속성·이온성·분자성·그물 공유성 네 가지예요. 단위세포당 원자 수는 SC 1, BCC 2, FCC 4이고, 밀도는 (원자 수 × M / N_A) / a³예요.
  • Bragg 법칙 nλ = 2d sin θ로 X선 회절각에서 원자 층 사이 거리 d를 구해요.

11장 · 용액의 특성

  • 몰농도(용액 L 기준), 몰랄농도(용매 kg 기준), 질량 백분율, 몰분율. 서로 바꿀 때는 밀도가 열쇠예요.
  • "비슷한 것끼리 녹는다." 기체 용해도는 압력이 오르면 늘고(Henry 법칙), 온도가 오르면 줄어요.
  • 총괄성은 입자의 종류가 아니라 수에만 의존해요: 증기압 내림 P = χP°, 끓는점 오름 ΔT_b = iK_b m, 어는점 내림 ΔT_f = iK_f m, 삼투압 π = iMRT.
  • van't Hoff 계수 i는 녹아서 생기는 입자 수예요(NaCl 2, CaCl₂ 3). 실제로는 이온쌍 때문에 예상보다 조금 작아요.

12장 · 화학 반응 속도론

  • 속도 법칙 속도 = k[A]^m[B]^n의 차수는 실험으로만 정해요. 균형 반응식의 계수와는 상관없어요.
  • 초기 속도법: 한 물질의 농도만 바꾼 두 실험을 나눠 차수를 구해요. 2배 → 2배면 1차, 4배면 2차예요.
  • 적분 속도식에서 직선이 되는 그래프로 차수를 판별해요: 0차 [A], 1차 ln[A], 2차 1/[A] 대 t. 1차 반감기는 0.693/k로 농도와 무관해요.
  • 메커니즘에서는 가장 느린 단계가 속도를 정해요. 중간체가 속도식에 남으면 앞의 빠른 평형으로 바꿔 넣어요.
  • 아레니우스 식 k = A·e^(−Ea/RT). 두 온도의 k로 활성화 에너지를 구해요.

13장 · 화학 평형

  • 평형은 정반응 속도와 역반응 속도가 같은 동적 상태예요. 농도는 일정하지만 서로 같을 필요는 없어요.
  • 반응식을 뒤집으면 1/K, n배 하면 Kⁿ, 두 반응을 더하면 K₁K₂예요. Kp = K(RT)^Δn.
  • 순수한 고체와 액체는 평형식에 쓰지 않아요.
  • Q < K면 정반응, Q > K면 역반응 쪽으로 가요. ICE 표로 평형 농도를 구하고, 음수가 되는 근은 버려요.
  • 르샤틀리에 원리: 자극을 줄이는 방향으로 이동해요. K를 바꾸는 건 온도뿐이에요.

14장 · 산과 염기

  • Arrhenius(H⁺/OH⁻를 냄), Brønsted–Lowry(양성자 주개/받개), Lewis(전자쌍 받개/주개) 순으로 정의가 넓어져요.
  • Kw = [H⁺][OH⁻] = 1.0 × 10⁻¹⁴(25 °C), Ka × Kb = Kw. 강산은 HCl, HBr, HI, HNO₃, H₂SO₄, HClO₃, HClO₄ 정도로 적어요.
  • 약산의 [H⁺]는 x ≈ √(Ka·C)로 근사하고, x/C가 5% 미만인지 확인해요.
  • 다양성자산은 Ka 차이가 커서 pH를 첫 단계만으로 구해요.
  • 염의 액성: 약산의 짝염기(F⁻)가 있으면 염기성, 약염기의 짝산(NH₄⁺)이 있으면 산성, 강산·강염기에서 온 이온만 있으면 중성이에요.
  • 산소산은 산소가 많을수록, 중심 원자의 전기음성도가 클수록 강해요. HX는 H–X 결합이 약할수록 강해요(HF는 약산).

재료물성개론 Materials Properties · 1–6주차

1주차 · 결함과 열역학

  • 결함은 차원으로 나눠요: 0D 점결함, 1D 전위, 2D 면결함(결정립계·표면), 3D 체적결함(void·crack).
  • 빈자리를 만들면 결합 에너지가 들지만(ΔH > 0) 배열의 경우의 수가 늘어요(ΔS > 0). ΔG = ΔH − TΔS 때문에 T > 0에서는 결함이 조금 있는 결정이 더 안정해요.
  • 다이아몬드 → 흑연은 ΔG < 0으로 자발적이지만 매우 느려요. 열역학은 방향을, 동역학은 속도를 정해요.

2주차 · 점결함

  • 빈자리, 침입형 원자, 치환형 불순물 세 가지예요.
  • ΔG = nΔH_v − kT ln W를 n으로 미분해 0으로 두면(Stirling 근사) 평형 빈자리 수 N_v = N·exp(−Q_v/kT)가 나와요.
  • ln(N_v/N)을 1/T에 대해 그리면 기울기 −Q_v/k인 직선이라, 두 온도의 데이터로 Q_v를 거꾸로 구할 수 있어요.
  • 이온결정은 전하 중성을 지키는 짝으로 결함이 생겨요: Schottky(양·음이온 빈자리 한 쌍), Frenkel(빈자리 + 침입형 이온). 경우의 수가 제곱이라 지수에 2가 붙어요.
  • 전하가 다른 불순물이 들어가면 합이 0이 되도록 빈자리가 생겨요(예: CaO에 Li₂O → Li⁺ 2개당 O 빈자리 1개).

3–4주차 · 선결함과 면결함

  • 소성변형은 원자면이 미끄러지는 slip이고, slip을 실제로 해내는 것이 전위예요. 면 전체를 한 번에 밀지 않고 결합을 한 줄씩 바꿔 가요(카펫의 주름).
  • Burgers 벡터 b는 전위를 둘러싼 회로가 닫히지 않는 틈이에요. b ⊥ 전위선이면 칼날 전위, b ∥ 전위선이면 나사 전위예요.
  • 칼날 전위는 미끄럼면이 하나로 정해지고, 나사 전위는 전위선을 지나는 어느 면으로든 갈아탈 수 있어요(cross-slip).
  • Glide는 확산 없이 저온에서도 일어나고, climb은 빈자리 확산이 필요해 고온에서 활발해요.
  • FCC는 조밀면과 방향이 많아 연성이 좋고, HCP는 slip 방법이 적어 연성이 낮아요.

5주차 · 유리

  • 유리는 단거리 질서는 있지만 장거리 주기성이 없는 비정질 고체예요.
  • 결정화는 Tm에서 부피가 뚝 떨어지지만, 유리는 Tm을 지나 과냉각 액체로 내려오다 Tg에서 기울기가 꺾여요.
  • 내부 시간척도 τ(원자 재배열에 필요한 시간)보다 냉각 시간 Δt가 짧으면 구조가 얼어붙어 유리가 돼요.
  • 빨리 식힐수록 Tg가 높고 덜 조밀해요. 그래서 유리 전이는 상전이가 아니라 동역학적 전이예요.

6주차 · 확산

  • 고체 확산은 빈자리 확산(치환형 원자)과 침입형 확산(C, N, H처럼 작은 원자)으로 일어나요. 침입형이 보통 더 빨라요.
  • Fick 1법칙 J = −D(dC/dx): 농도 기울기를 따라 흐르는 양이에요.
  • 확산계수는 D = D₀·exp(−Q_d/RT)로 온도에 지수적으로 의존해요. ln D 대 1/T 기울기에서 Q_d를 구해요.
  • Fick 2법칙 ∂C/∂t = D(∂²C/∂x²)는 질량 보존에서 나와요. 표면 농도가 일정하면 해가 erf 함수로 주어져요(침탄).

재료화학개론 Introduction to Solid State Chemistry · 1–5장

1 · 원자와 전자 구조

원자와 핵
  • 원자는 양성자(+1)와 중성자(0)로 된 핵을 전자가 둘러싼 구조예요. 원자 크기는 약 10⁻¹⁰ m(1 Å), 핵은 약 10⁻¹⁵ m로 원자보다 10만 배 작아요.
  • 원자번호 Z는 양성자 수, 질량수는 A = Z + N(N은 중성자 수)이에요. Z가 같고 N이 다른 원자를 동위원소라고 해요(¹H, ²H, ³H).
  • 1 amu는 탄소-12 원자 질량의 1/12(1.6603 × 10⁻²⁷ kg)예요. 양성자 1.0073, 중성자 1.0087, 전자 0.00055 amu로, 질량은 거의 핵에 몰려 있어요.
  • 핵의 질량은 구성 입자 질량의 합보다 작아요. 이 차이(질량 결손 Δm)가 핵의 결합 에너지 ΔE = Δm·c²이고, 원자번호가 중간인 Fe 근처에서 가장 커요.
  • 양성자와 중성자 비율이 불안정한 핵은 α 입자나 β 입자를 내며 붕괴하고, 절반이 붕괴하는 데 걸리는 시간이 반감기예요(⁶⁰Co 약 5.3년).
Bohr 모형
  • 가정: 전자는 정해진 원 궤도에서만 돌고, 각운동량은 mvr = nh/2π로 양자화돼요. 원심력과 쿨롱 인력이 같다는 조건 mv²/r = e²/(4πε₀r²)과 합치면 궤도 반지름과 에너지가 나와요.
  • 궤도 반지름 r_n = n²·(0.529 Å), 에너지 E_n = −13.6/n² eV. 핵에서 멀수록 에너지가 높고(0에 가까움), 묶인 전자의 에너지는 항상 음수예요(자유 전자 = 0).
  • 전자가 위 궤도로 올라가려면 그 차이만큼 빛을 흡수하고, 내려올 때 내놓아요: ΔE = hν = hc/λ. 파수로 쓰면 1/λ = R(1/n_f² − 1/n_i²), R = 1.097 × 10⁷ m⁻¹.
  • n = 1로 떨어지면 Lyman(자외선), n = 2면 Balmer(가시광선), n = 3이면 Paschen(적외선) 계열이에요.
Bohr 모형 이후
  • Bohr 모형은 전자가 많은 원자와 자기장 속에서 갈라지는 스펙트럼선을 설명하지 못했어요. Sommerfeld가 궤도 모양(l), 자기장 속 방향(m), 스핀(s)을 더했어요.
  • de Broglie: 움직이는 모든 물질은 파동성을 가져요(λ = h/mv = h/p). 전자를 V 볼트로 가속하면 λ = h/√(2meV)예요.
  • Heisenberg 불확정성 원리 Δx·Δp ≥ h: 위치와 운동량을 동시에 정확히 알 수 없어요. 그래서 전자의 위치는 궤도가 아니라 확률(전자구름, |ψ|²)로 나타내요.
네 양자수와 오비탈
  • s(l = 0)는 공 모양 1개, p(l = 1)는 아령 모양 3개(px, py, pz), d(l = 2)는 5개, f(l = 3)는 7개 오비탈이에요. 오비탈 하나에 전자가 2개까지 들어가니 각각 2, 6, 10, 14개예요.
  • 껍질 하나에는 전자가 2n²개까지 들어가요: K 2, L 8, M 18, N 32.

전자를 채우는 규칙
  • 파울리 배타 원리: 한 원자 안의 두 전자는 네 양자수가 모두 같을 수 없어요. 그래서 오비탈 하나에는 스핀이 반대인 전자 두 개까지만 들어가요.
  • 쌓음 원리(Aufbau): 에너지가 낮은 오비탈부터 채워요. 4s가 3d보다 먼저 채워지는 것이 대표적인 예외예요.
  • Hund 규칙: 같은 에너지의 오비탈(예: p 세 개)에는 먼저 한 개씩 같은 스핀으로 들어간 뒤 짝을 지어요. 탄소 2p²는 서로 다른 p 오비탈에 하나씩 들어가요.
  • 이온은 바깥 전자부터 잃어요. Fe [Ar]3d⁶4s² → Fe²⁺ [Ar]3d⁶ → Fe³⁺ [Ar]3d⁵. 4s를 먼저 채웠지만 먼저 잃어요.
이온화 에너지 · 전자 친화도 · 원자 크기
  • 이온화 에너지는 가장 약하게 묶인 전자 하나를 떼는 데 드는 에너지예요(eV). 닫힌 껍질의 비활성 기체가 가장 크고, s 전자 하나가 남은 알칼리 금속이 가장 작아요(Li 5.39 eV).
  • 전자 친화도는 전자를 하나 받을 때 나오는 에너지예요. 할로젠처럼 전자 하나만 받으면 닫힌 껍질이 되는 비금속이 크고, 금속과 비활성 기체는 작아요.
  • 전자구름에 경계가 없어서 원자 크기는 정의하기 나름이에요. 고립된 원자는 van der Waals 반지름, 결합한 원자는 원자 간 거리의 절반으로 정해요(H₂ 결합 길이 0.74 Å → H 반지름 0.37 Å).

2 · 화학 결합

결합의 종류
  • 비활성 기체는 s와 p가 꽉 찬 ns²np⁶ 구조라 가장 안정해요. 다른 원자는 전자를 주고받거나 공유해서 이 구조에 가까워지려고 하고, 그것이 결합이에요.
  • 1차 결합은 이온 결합(전자 이동), 공유 결합(전자 공유), 금속 결합(퍼진 전자 기체)이고, 2차 결합은 쌍극자 사이 인력, 분산력, 수소결합이에요. 실제 결합은 대부분 이온성과 공유성 사이 어딘가에 있어요.
이온 결합과 격자 에너지
  • 1–3족 원소는 전자를 1–3개 잃어 양이온, 15–17족 원소는 전자를 3–1개 얻어 음이온이 되고, 반대 전하가 정전기적으로 끌어당겨요. 인력은 모든 방향으로 같아서 방향성이 없어요.
  • 두 이온 사이 에너지는 E = −e²/(4πε₀r)·N_A + b/rⁿ이에요. 가까워지면 전자구름이 겹쳐 반발이 급격히 커져서, 인력과 반발이 균형을 이루는 거리 r₀에서 에너지가 가장 낮아요.
  • 이온 결정 1몰의 격자 에너지(Born–Landé): E = −M·N_A·Q₁Q₂e²/(4πε₀r₀)·(1 − 1/n). M은 결정 구조에 따라 정해지는 Madelung 상수, n은 반발 지수(NaCl은 n ≈ 12)예요.

공유 결합: σ와 π
  • 각 원자의 홀전자 오비탈이 겹치고 스핀이 짝을 지어 전자쌍을 공유해요. 두 핵 사이에 전자가 있을 확률이 커지고, 오비탈이 겹치는 방향으로만 결합하니 방향성이 강해요.
  • σ 결합: 두 핵을 잇는 축을 따라 정면으로 겹쳐요(s–s, s–p, p–p, 혼성 오비탈). π 결합: 혼성에 쓰이지 않은 p 오비탈이 옆으로 겹쳐요.
  • 단일 결합은 σ 1개, 이중 결합은 σ 1 + π 1(C₂H₄), 삼중 결합은 σ 1 + π 2(C₂H₂)예요. C₂H₆은 σ 7개(C–C 1, C–H 6)예요.
  • 다른 원자끼리 공유하면 전기음성도가 큰 쪽으로 전자가 치우쳐 부분 전하가 생겨요(H^δ+–Cl^δ−, 영구 쌍극자). 같은 원자끼리(H₂, Cl₂)는 극성이 없어요.
혼성 오비탈과 분자 모양
  • 탄소 2s²2p²는 2s 전자 하나를 2p로 올려 2s¹2p³가 되고, 네 오비탈이 섞여 똑같은 sp³ 오비탈 4개가 돼요. 이 넷이 정사면체 꼭짓점을 향해서 결합각이 109.5°예요(CH₄, CCl₄, 다이아몬드).
  • sp²: s 하나와 p 둘이 섞여 평면 삼각형, 120°(BF₃, C₂H₄). 남은 p 하나가 π 결합을 만들어요.
  • sp: s 하나와 p 하나가 섞여 직선형, 180°(BeH₂, CO₂, C₂H₂). 남은 p 둘이 π 결합 두 개를 만들어요.
  • 결합에 극성이 있어도 모양이 대칭이면 쌍극자가 상쇄돼 비극성이에요: CH₄, CCl₄, BF₃, CO₂, BeH₂는 비극성, H₂O(굽은형)와 CH₃Cl은 극성이에요.
금속 결합과 2차 결합
  • 금속의 원자가 전자는 핵에 약하게 묶여 원자에서 떨어져 나와요. 양이온 격자를 "자유 전자 기체"가 묶어 주는 것이 금속 결합이고, 전기·열 전도와 연성이 여기서 나와요.
  • 영구 쌍극자 인력: 극성 분자끼리 끌어당겨요(물, 알코올). 열운동이 방향을 흐트러뜨려 온도가 오르면 약해져요.
  • 유도 쌍극자: 극성 분자가 옆 비극성 분자의 전자를 조금 밀어 쌍극자를 만들어요.
  • 분산력(London): 모든 원자와 분자에서 전자 분포가 순간순간 흔들리며 생기는 쌍극자끼리의 인력이에요(E ∝ −1/r⁶). 비활성 기체와 메테인 같은 비극성 분자를 묶어요.
  • 수소결합: H가 O, N, F에 붙으면 H 쪽이 강한 양전하를 띠어 이웃 분자의 O, N, F와 다리를 놓아요. 다른 2차 결합보다 강하지만 공유 결합보다는 약하고, 생체 분자를 안정하게 해요.
결합 에너지와 전기음성도 (Pauling)
  • 순수 공유 결합 에너지는 두 동핵 결합 에너지의 기하평균 √(BE_AA·BE_BB)로 어림해요. 실제 결합 에너지가 이보다 큰 만큼(Δ)이 이온성 기여예요.
  • HCl: √(430 × 238) = 320 kJ/mol인데 실제는 426 kJ/mol이라 Δ = 106 kJ/mol. Pauling은 이것을 Δ = 96.3(χ_A − χ_B)²로 전기음성도 차이와 이었어요.
  • 전기음성도는 단위 없는 상대값이에요(H = 2.2 기준). 차이가 대략 1.7보다 크면 이온 결합, 작으면 공유 결합 성격이 강해요.

3 · 에너지 띠

고전 모형의 한계
  • Drude–Lorentz의 "전자 바다" 모형은 금속을 양이온과 자유 전자 기체로 봐요. 전도는 설명하지만 전자를 고전 입자로 다뤄서 금속의 비열을 맞게 예측하지 못했어요. 전자는 양자 규칙(Fermi–Dirac 통계)을 따라요.
국소화된 파동과 비국소화된 파동
  • 전자는 입자이면서 파동이고, |ψ|²는 그 위치에 전자가 있을 확률이에요.
  • 원자 하나의 1s 전자나 두 원자 사이 결합 전자는 특정 공간에 확률이 모여 있어요(국소화).
  • 결정 속 원자가 전자의 파동함수는 모든 원자에 걸쳐 퍼져 있어요(비국소화). 전자가 어느 한 원자에 묶여 있지 않아서 결정 전체를 움직일 수 있어요.
원자가 모이면 준위가 띠가 된다 (LCAO)
  • 두 원자가 가까워지면 같은 준위 두 개가 섞여 낮은 결합 상태(σ)와 높은 반결합 상태(σ*)로 갈라져요. 결정은 원자 오비탈의 선형 결합(LCAO)으로 된 거대한 분자라고 볼 수 있어요.
  • 원자가 N개면 상태도 정확히 N개로 갈라져요(상태 수 = 원자 수). N이 홀수면 가운데에 비결합 상태가 하나 생겨요(Li 원자 3개, 11개). 짝수면 생기지 않아요.
  • N이 10²³ 정도가 되면 상태 사이 간격이 약 10⁻²⁰ eV로 줄어 사실상 연속인 띠가 돼요. 띠의 폭은 결정 구조와 가장 가까운 이웃의 수에 따라 달라요.
  • 전자는 아래 상태부터 채워지고, 상태(파수 k) 하나에 스핀이 반대인 전자 두 개까지 들어가요(파울리). Li처럼 원자마다 전자가 하나면 s 띠의 아래 절반이 채워져요.
금속 · 반도체 · 절연체
  • 꽉 찬 띠 중 가장 위가 원자가띠(VB, 결합 오비탈), 그 위의 빈 띠가 전도띠(CB, 반결합 오비탈), 그 사이 전자가 있을 수 없는 구간이 띠간격 E_g예요.
  • 금속: 띠가 일부만 차 있거나(Li 2s) 두 띠가 겹쳐 있어서, 아주 작은 에너지로도 전자가 빈 상태로 옮겨 가 전류가 흘러요.
  • 반도체: 띠간격이 작아요(Si 약 1.1 eV). 열이나 빛으로 일부 전자가 전도띠로 올라가요.
  • 절연체: 띠간격이 커요(대략 4 eV 이상, 다이아몬드 약 5.5 eV). 전자가 거의 올라가지 못해 전류가 흐르지 않아요.
  • 띠간격보다 에너지가 큰 빛만 흡수돼요: λ = 1240/E_g(eV) nm. Si는 약 1.13 μm보다 짧은 빛을 흡수하고, ZnO(3.2 eV)와 다이아몬드는 가시광선을 흡수하지 않아 투명해요.
도핑
  • 순수(진성) Si에서는 전도띠로 올라간 전자 수와 원자가띠에 남은 정공 수가 같아요(n = p).
  • 15족 P를 넣으면 전자 하나가 남아 전도띠 바로 아래 준위에서 쉽게 올라가요(주개, n형). 13족 B를 넣으면 전자 하나가 모자라 원자가띠 바로 위에 빈 준위가 생기고, 원자가띠에 정공이 남아요(받개, p형).

4 · 결정 구조

고체와 결정
  • 고체가 되느냐는 원자 사이 인력과 원자를 흩뜨리는 열운동의 경쟁이에요. 인력이 이기면 원자가 규칙적인 3차원 무늬로 늘어서고, 이 규칙성이 결정성이에요.
  • 결합에 따라 이온성(NaCl), 공유성(다이아몬드), 금속성(Fe, Ni), van der Waals(얼음, 고체 He) 고체로 나눠요.
  • 단결정은 전체가 하나의 결정이고, 다결정은 방향이 제각각인 작은 단결정(결정립)들이 모인 것이에요.
공간 격자 · 기저 · 단위세포
  • 공간 격자는 3차원 직선망의 교점들이고, 모든 점의 주변 환경이 똑같아야 해요. 점들을 이렇게 배열하는 방법은 14가지뿐이에요.
  • 결정 구조 = 격자 + 기저(basis). 기저는 각 격자점에 놓이는 원자 묶음이에요. 같은 격자라도 기저가 다르면 전혀 다른 결정이 돼요.
  • 격자점의 위치는 1D r = ua, 2D r = ua + vb, 3D r = ua + vb + wc로 나타내요. 단위세포는 세 축 길이 a, b, c와 축 사이 각 α, β, γ로 정해요.
  • 단위세포는 크기, 모양, 방향이 같은 셀을 반복해 결정 전체를 채우는 벽돌이에요. 격자점이 하나만 들어 있는 가장 작은 셀이 기본 셀(primitive cell)이에요.
  • 셀당 격자점 세기: 꼭짓점 점은 8개 셀이 나눠 가져 1/8, 모서리 1/4, 면 1/2, 내부 1로 세요. 그래서 P(단순) 1, C(밑면 중심) 2, I(체심) 2, F(면심) 4개예요.
7 결정계와 14 Bravais 격자
  • 결정계 7개에 중심 위치(P, C, I, F)를 조합하면 14개예요. 모든 조합이 새 격자가 되지는 않아요. 예를 들어 밑면 중심 정방은 더 작은 단순 정방 셀로 다시 그릴 수 있어서 따로 세지 않아요.
  • HCP는 공간 격자가 아니에요. 셀 안쪽 원자의 주변 환경이 꼭짓점 원자와 달라서예요. HCP는 육방 P 격자에 원자 2개짜리 기저를 놓은 결정 구조예요.

SC · BCC · FCC

입방 격자 세 가지는 격자점이 놓이는 곳만 달라요. 단순 입방(SC)은 꼭짓점에만, 체심 입방(BCC)은 꼭짓점과 몸통 중심에, 면심 입방(FCC)은 꼭짓점과 여섯 면의 중심에 있어요. 원자를 공으로 보면 원자끼리 어느 방향으로 맞닿는지가 구조마다 달라서 반지름과 격자상수의 관계가 정해져요. 그림의 "원자 크기" 버튼을 누르면 실제로 맞닿는 크기로 바뀌어요.

조밀 쌓임: FCC와 HCP
  • 금속 원자는 자유 전자가 사방으로 고르게 묶어 주기 때문에, 크기가 같은 공을 최대한 빽빽하게 쌓는 구조를 만들기 쉬워요.
  • 2차원에서는 육방(삼각) 배열이 가장 조밀해요(0.907, 정사각은 0.785). 이 층의 오목한 자리(삼각형 홈)는 꼭짓점이 위로 향한 것과 아래로 향한 것 두 종류예요.
  • 첫 층을 A라 하면 둘째 층은 한 종류의 홈 위(B)에 놓여요. 셋째 층을 A 바로 위에 놓으면 ABAB… = HCP, 세 번째 자리 C에 놓으면 ABCABC… = FCC(입방 최조밀 쌓임)예요.
  • 둘 다 배위수 12, 충진율 0.74로 똑같이 조밀해요. HCP의 12는 같은 층 6 + 위층 3 + 아래층 3이에요. FCC에서는 조밀한 층이 {111} 면이에요.
  • 이상적인 HCP의 c/a = √(8/3) ≈ 1.633이에요. 실제 원자는 완전한 공이 아니어서 Be 1.58에서 Cd 1.89까지 달라요.
  • 쌓인 공 사이에는 사면체 빈자리(공 4개로 둘러싸임)와 팔면체 빈자리(공 6개)가 생겨요. 이온 결정에서 작은 이온이 이 빈자리에 들어가요.
이온 결정과 공유 결정
  • NaCl (암염 구조): 두 FCC 격자가 반 칸씩 엇갈려 겹친 구조예요. Cl⁻가 FCC 자리에, Na⁺가 모서리 중간과 몸통 중심(팔면체 빈자리)에 있어 셀당 Na 4, Cl 4개, 배위수 6이에요. Bravais 격자는 FCC이고 기저는 Na–Cl 한 쌍이에요.
  • NaCl 좌표: Cl (0,0,0), (½,½,0), (½,0,½), (0,½,½) / Na (½,0,0), (0,½,0), (0,0,½), (½,½,½). 산화물, 할로젠화물, 수소화물, 탄화물에서 흔해요.
  • CaF₂ (형석 구조): Ca²⁺가 FCC 자리(꼭짓점과 면 중심), F⁻가 몸통 대각선의 ¼ 지점, 즉 사면체 빈자리 8개를 모두 채워요. 셀당 Ca 4, F 8개로 1 : 2예요.
  • ZnS (섬아연석): S²⁻가 FCC 자리, Zn²⁺가 사면체 빈자리의 절반(4개)에 있어 1 : 1이에요.
  • CsCl: Cs⁺가 꼭짓점, Cl⁻가 몸통 중심이에요. 모양은 BCC 같지만 두 자리가 다른 이온이라 격자는 단순 입방이고, 기저가 이온 두 개예요.
  • 다이아몬드 입방: FCC 격자에 원자 두 개짜리 기저 (0,0,0), (¼,¼,¼)를 놓은 구조예요. 셀당 8개, 각 원자가 이웃 4개와 sp³ 정사면체 결합을 해요(C, Si, Ge, 저온의 Sn). 공유 결합 원소는 (8 − N) 규칙대로 이웃 수가 정해져요.
  • 페로브스카이트 ABX₃: A가 꼭짓점, B가 몸통 중심, X가 면 중심에 있어 B를 X 여섯 개가 팔면체로 둘러싸요(예: CaTiO₃).
방향 지수 [uvw]
  • 원점에서 그 방향의 한 점까지의 좌표를 a, b, c 단위로 읽고, 같은 비를 유지하며 가장 작은 정수로 만든 뒤 대괄호에 넣어요. 시작점이 원점이 아니면 (끝점 − 시작점)을 써요.
  • 예: 점 (3a, b, ½c) → (3, 1, ½) → 2를 곱해 [621]. 점 (2a, −b, ½c) → (2, −1, ½) → [421]. 음수는 숫자 위에 줄을 그어요.
  • x축 [100], y축 [010], z축 [001], xy면의 면 대각선 [110], 몸통 대각선 [111]이에요.
  • 방향을 구할 때는 역수를 쓰지 않아요. 역수는 면 지수에서만 써요. 이 차이가 가장 자주 나오는 함정이에요.
  • 방향 family ⟨uvw⟩: 대칭으로 서로 겹쳐지는 방향들의 모임이에요. 입방정에서 ⟨100⟩은 6개(±x, ±y, ±z), ⟨110⟩은 12개, ⟨111⟩은 8개 방향이에요.
  • 입방정에서는 방향 [hkl]이 같은 지수의 면 (hkl)에 수직이에요.
면 지수 (hkl): 밀러 지수
  • 1) 면이 x, y, z축과 만나는 절편을 a, b, c의 배수로 읽어요. 2) 역수를 취해요. 3) 같은 비의 가장 작은 정수로 줄여요. 4) 소괄호에 넣어요: (hkl).
  • 축과 평행하면 절편이 ∞라서 역수가 0이에요. 절편 (1, 1, ∞) → (1, 1, 0) → (110). 절편 (½, 1, ∞) → (2, 1, 0) → (210). 절편 (½, ½, 1) → (2, 2, 1) → (221).
  • 면이 원점을 지나면 절편을 읽을 수 없으니 원점을 옮겨요. 음의 절편은 지수 위에 줄을 그어요. 예: 원점을 (0, 1, 0)으로 옮기면 절편 (∞, −1, ½) → (012).
  • (hkl)은 면 하나가 아니라 서로 평행하고 간격이 같은 면 전체의 집합이에요. 그래서 (hkl)과 (111)처럼 부호를 모두 바꾼 지수는 같은 면 집합이에요.
  • 회절에서는 (020)처럼 공약수를 남긴 지수를 쓰기도 해요. (020)은 (010)과 같은 방향이지만 간격이 절반인 면 집합이에요(y = ½에서 만남).
  • 입방정의 면간 거리 d_hkl = a / √(h² + k² + l²). 지수가 클수록 면 사이가 좁고, 면 위의 원자는 드물어요.
면 family {hkl}
  • 결정의 대칭으로 서로 겹쳐지는, 즉 원자 배열과 면간 거리가 같은 면들의 모임을 {hkl}로 써요. 성질이 같아서 회절에서도 같은 봉우리를 만들어요.
  • 입방정 {100} = (100), (010), (001), (100), (010), (001): 정육면체의 여섯 면이에요.
  • 입방정 {110} = (110), (101), (011), (110), (101), (011), (110), (101), (011), (110), (101), (011): 12개, 정육면체를 대각선으로 자르는 면들이에요.
  • 입방정 {111} = 8개: 정육면체의 꼭짓점을 잘라내는 면들로, 팔면체의 면이에요.
  • family는 결정계에 따라 달라져요. 사방정(a ≠ b ≠ c)에서는 (100)과 (010)의 간격이 달라 같은 family가 아니에요. 그래서 {110} = (110), (110), (110), (110) 4개뿐이고, {101}과 {011}은 따로예요.

5 · X선과 X선 회절

X선은 어디서 오나
  • Röntgen이 발견했고, Laue는 결정이 공간 격자로 된 원자 배열이라 X선을 회절시킨다는 것으로 X선이 파동임을 보였어요.
  • 수소꼴 원자에서 전이 에너지는 1/λ = RZ²(1/n_f² − 1/n_i²)로 원자번호의 제곱에 비례해요. 그래서 무거운 원자의 안쪽 껍질 전이는 파장이 10⁻⁷ m에서 10⁻¹⁰ m 영역(X선)까지 짧아져요.
  • 모든 전이에는 먼저 빈자리가 필요해요. 안쪽 껍질은 꽉 차 있어서, 빈자리가 없으면 위 전자가 내려올 곳이 없어요.
X선관과 연속 스펙트럼
  • 가열한 필라멘트(음극)에서 나온 전자를 1–50 kV로 가속해 금속 타깃(양극, 물로 냉각)에 부딪혀요.
  • 전자가 타깃 원자의 전기장에서 감속되며 에너지 일부를 X선으로 내놓아요(제동 복사, Bremsstrahlung). 잃는 에너지가 제각각이라 파장이 연속적으로 퍼져요.
  • 전자의 운동 에너지가 한 번에 전부 광자 하나가 되면 가장 짧은 파장이 나와요: eV = hν_max = hc/λ_SWL → λ_SWL = hc/eV = 12.398/V(kV) Å. 30 kV면 0.413 Å이고, 전압을 높이면 더 짧아져요.
특성 X선: Kα와 Kβ
  • 입사 전자가 K 껍질 전자를 쳐내 빈자리를 만들면, 위 껍질 전자가 내려오며 그 차이만큼의 X선을 내요. L → K(n = 2 → 1)가 Kα, M → K(3 → 1)가 Kβ예요.
  • Kβ는 에너지 차이가 더 커서 에너지가 크고 파장이 짧아요(Mo: Kα 0.7101 Å, Kβ 0.6323 Å). Kα가 더 자주 일어나 더 세요. Kα 뒤에는 L에, Kβ 뒤에는 M에 빈자리가 남아요.
  • n = 3 → 2, 4 → 2 전이는 Lα, Lβ로 더 긴 파장에 나타나요.
  • 미세 구조: 껍질 안에도 s, p, d 부준위가 있어서 Kα 선은 Kα₁과 Kα₂ 두 줄로 갈라져요.
  • 특성선은 원소마다 정해져 있어 정량 화학 분석에 쓰여요(주사 전자 현미경과 결합).
Moseley 법칙과 가림 효과
  • Moseley는 특성선 진동수의 제곱근이 원자번호에 비례한다는 것을 찾았어요(√ν ∝ Z, 그래서 λ(Kα) ∝ 1/Z²).
  • 1/λ = R(Z − σ)²(1/n_f² − 1/n_i²). σ는 가림 상수로, 안쪽 전자가 핵 전하를 일부 가려서 실제로 느끼는 전하가 Z − σ로 줄어드는 효과예요. Kα는 σ ≈ 1, Lα는 σ ≈ 7.4예요.
  • 예: Cu(Z = 29) Kα ≈ 1/(0.75 × 1.097 × 10⁷ × 28²) ≈ 1.55 Å (실측 1.542 Å). 전자가 하나뿐인 수소꼴 원자에는 가릴 안쪽 전자가 없어 σ = 0이에요.
연 X선과 에너지 띠의 증거
  • K 빈자리가 연쇄적으로 내려가다 2p에 빈자리가 생기면, 3s 전자가 채우며 에너지가 작고 파장이 긴 연 X선을 내요.
  • Na 기체는 3s가 준위 하나라 파장이 하나로 정해져요(약 36.8 nm). Na 고체는 3s가 띠를 이뤄 파장이 퍼져요. 이 퍼짐의 폭과 세기 분포가 띠의 폭과 상태 밀도를 직접 보여 줘요.
회절과 Bragg 법칙
  • 파장이 물체 간격과 비슷하면 회절이 일어나요. X선 파장(0.1–10 Å)은 원자 간격과 같은 크기라 결정 구조를 볼 수 있어요. 가시광선은 너무 길어요.
  • 단색 X선을 쓰고, 원자면을 거울처럼 생각해요. 아래 면에서 반사된 빛은 2d·sin θ만큼 더 가요. 이 경로차가 파장의 정수배일 때 보강 간섭이 일어나요: 2d_hkl·sin θ = nλ.
  • θ는 입사 X선과 원자면 사이 각이고, 검출기는 입사 방향에서 2θ에 있어요.
  • 봉우리 위치(2θ)는 면간 거리 → 격자상수(부피)와 격자 종류(모양)를 알려 줘요. Bragg 법칙은 셀 안 원자의 위치를 다루지 않아요.
  • 봉우리 세기는 셀 안 모든 원자가 산란한 파동의 위상 관계에 달려 있어서, 원자 위치는 세기에서 알 수 있어요.
소멸 규칙과 격자 판별
  • 왜 사라지나: BCC의 (100) 면 사이 정확히 가운데에 몸통 중심 원자로 된 면이 또 있어요. 이 면에서 반사된 빛은 반 파장 늦어 (100) 반사를 지워요. (200)은 그 면까지 포함한 간격이라 남아요.

  • SC는 1 : 2 : 3 : 4 : 5 : 6 : 8(7은 만들 수 없음), BCC는 2 : 4 : 6 : 8 : 10, FCC는 3 : 4 : 8 : 11 : 12. 비를 보고 격자를 판별하는 과정이 indexing이에요.
  • 파장이 고정이면 θ가 가장 작은 봉우리는 d가 가장 큰 면이라, SC (100), BCC (110), FCC (111)이 첫 봉우리예요.

9장 전체의 목표는 연립일차방정식을 푸는 것이에요. 9.1에서 계수를 담는 도구(행렬)를 만들고, 9.2–9.5에서 네 가지 방법으로 풀어요: 행렬식으로 해가 하나인지 판정하고(9.2), 손으로 소거하고(9.3), 역행렬로 나누고(9.4), 행렬식만으로 바로 답을 뽑아요(9.5).

9.1 행렬과 연산

  • 숫자를 직사각형으로 늘어놓은 것이 행렬이에요. m개의 행(가로줄)과 n개의 열(세로줄)이면 m × n 행렬이고, a_ij는 i행 j열 성분이에요. 순서는 언제나 (행, 열).
  • m = n이면 정사각행렬, a₁₁에서 aₙₙ을 잇는 대각선이 주대각선이에요. n × 1은 열벡터, 1 × n은 행벡터예요.
  • 덧셈과 스칼라배는 같은 자리끼리 계산해서 실수처럼 교환·결합·분배법칙이 모두 성립해요.
  • 곱셈: (AB)_ij = Σ a_ik·b_kj. A의 i행과 B의 j열이 만나 한 칸을 만들어요. (m×p)(p×n) = m×n처럼 가운데 p가 맞아야 정의돼요.
  • 왜 이렇게 정의했나: 연립방정식을 AX = B 한 줄로 쓰기 위해서예요. 계수 행 (1, 2, 3)과 미지수 열 (x, y, z)이 만나면 x + 2y + 3z가 되고, 행 하나가 방정식 하나예요.

9.2 행렬식

  • ax + by = e, cx + dy = f를 가감법으로 풀면 x = (ed − bf)/(ad − bc)예요. 분모 ad − bc가 0이면 해가 하나로 정해지지 않아서, 이 값을 행렬식(determinant)이라고 불러요.
  • 정사각행렬에만 정의되고 det A 또는 |A|로 써요. |A|는 절댓값이 아니라서 음수도 나와요. det A = 0이면 특이행렬(해가 유일하지 않음, 역행렬 없음), det A ≠ 0이면 정칙행렬이에요.
  • 3 × 3 행렬식은 6항이에요. 모든 항이 각 행에서 하나씩, 같은 열은 두 번 쓰지 않게 뽑은 곱이에요(체스판에 서로 잡지 않게 룩 3개 놓기, 3 × 2 × 1 = 6가지). 행과 열이 대등하게 들어가 있어서 아래 성질이 모두 나와요.
  • 소행렬식 M_ij는 i행 j열을 지운 행렬의 행렬식, 여인수는 C_ij = (−1)^(i+j)·M_ij예요. 부호판 + − + / − + − / + − +는 i + j를 매번 계산하지 않으려는 표예요.
  • 여인수 전개: det A = a_i1·C_i1 + a_i2·C_i2 + … + a_in·C_in. 어느 행이나 열로 전개해도 같아서, 0이 가장 많은 줄을 고르면 계산이 그만큼 줄어요.

행렬식의 성질

  • (iv)의 증명: 두 행이 같으면 바꿔도 행렬이 그대로인데, (iii)에 따라 부호는 반대여야 해요. det A = −det A를 만족하는 수는 0뿐이에요.
  • (v)의 증명: 1행에 2행의 k배를 더하면 각 항이 둘로 갈라지고, 뒤 조각들의 합은 1행 자리에 2행을 복사한 행렬의 행렬식 × k예요. 행이 중복되니 (iv)에 의해 0이라 det은 그대로예요.
  • (viii)에서 det(AB) = 0 ⟺ det A = 0 또는 det B = 0. 또 det(AB) = det(BA)라서, 행렬 자체는 순서에 민감해도 행렬식은 그렇지 않아요.
  • n × n에서 det(kA) = kⁿ·det A예요. 모든 행에 k가 곱해지니까요.
  • 행축소법: (v)로 대각선 아래를 0으로 만든 뒤 (vii)로 대각선을 곱해요. 행을 바꾸면 부호를 뒤집고, 행 전체에 k를 곱하면 k배를 추적해요. 도착하는 행의 계수가 1인지 확인하세요: 4R₁ + R₂ → R₂는 그대로지만, R₁ + 4R₂ → R₂는 4배가 돼요.
성질내용넓이로 보면
(i)한 행에 k를 곱하면 det도 k배한 변이 k배
(ii)한 행이 모두 0이면 det = 0평행사변형이 안 생김
(iii)두 행을 바꾸면 부호가 반대방향이 뒤집힘
(iv)두 행이 같거나 비례하면 det = 0두 변이 평행해 납작
(v)한 행에 다른 행의 상수배를 더해도 det 그대로옆으로 밀리기만 함
(vi)det A = det Aᵀ행에 대한 성질이 열에도 성립
(vii)삼각행렬의 det = 대각성분의 곱0이 많은 열로 전개하면 끝
(viii)det(AB) = det A · det B곱셈과는 맞음
(ix)det(A + B) ≠ det A + det B덧셈과는 안 맞음

9.3 선형계와 가우스 소거법

  • AX = B에서 A는 계수행렬(m × n), X는 미지수 열벡터(n × 1), B는 우변 열벡터(m × 1)예요. X와 B가 세로여야 곱셈의 크기가 맞아요.
  • B가 모두 0이면 제차 선형계예요. 제차 선형계는 x₁ = … = xₙ = 0(자명해)을 항상 가지므로 해가 없는 경우가 없어요.
  • 기본 행연산 세 가지: 두 행 교환, 한 행에 0이 아닌 수 곱하기, 한 행에 다른 행의 상수배 더하기. 해를 구할 때는 det가 변해도 상관없어요(해는 그대로). 행렬식을 구할 때와 목적이 달라요.
  • 첨가행렬 [A | B]를 사다리꼴로 만든 뒤 0만 있는 행을 뺀 행의 수를 r(계수, rank), 미지수 수를 n이라 하면 해의 종류가 정해져요.
  • r < n이면 미지수 하나를 t처럼 자유롭게 두고(자유변수) 나머지를 t로 나타내요. 한 식의 좌변이 다른 식들의 조합인데 우변이 맞지 않을 때가 해가 없는 진짜 원인이에요.
  • 정리 9.8: n × n 제차 선형계 AX = O가 자명하지 않은 해를 가질 필요충분조건은 det A = 0이에요.
  • 응용: 화학 반응식 aC₂H₆ + bO₂ → cCO₂ + dH₂O는 원소별 개수를 맞추면 제차 선형계가 돼요. d를 자유롭게 두면 a = d/3, b = 7d/6, c = 2d/3이라 d = 6으로 잡아 2C₂H₆ + 7O₂ → 4CO₂ + 6H₂O. 전기회로는 저항마다 IR만큼 전압이 떨어지고 닫힌 고리를 돌면 합이 0이라는 식으로 세워요.

9.4 역행렬

  • AB = BA = I이면 B = A⁻¹이에요. 정의가 양쪽을 요구하므로, 검산할 때도 AB = I와 BA = I를 둘 다 보이는 게 안전해요.
  • 성질: (i) (A⁻¹)⁻¹ = A, (ii) (AB)⁻¹ = B⁻¹A⁻¹(전치처럼 순서가 뒤집힘), (iii) (Aᵀ)⁻¹ = (A⁻¹)ᵀ, (iv) det A⁻¹ = 1/det A (AA⁻¹ = I에 (viii)을 쓰면 det A·det A⁻¹ = det I = 1).
  • 가우스–요르단법: [A | I]를 만들고, 왼쪽이 I가 될 때까지 행연산을 하면 오른쪽에 A⁻¹이 남아요. 아래쪽 소거 → 대각성분을 1로 → 위쪽 소거 순서예요.
  • 딸림행렬: adj A = [C_ij]ᵀ(여인수 행렬의 전치), det A ≠ 0이면 A⁻¹ = adj A / det A. A·adj A의 대각선 밖 성분은 행이 중복된 행렬의 행렬식이라 0이 되기 때문이에요.
  • 2 × 2 전용: [[a, b], [c, d]]⁻¹ = [[d, −b], [−c, a]] / (ad − bc). 대각선은 자리를 바꾸고, 나머지 둘은 부호만 바꾼 뒤 행렬식으로 나눠요.
  • 정리 9.11: A⁻¹이 있으면 AX = B의 해는 X = A⁻¹B 하나뿐이에요. 그래서 "det A ≠ 0 ⟺ 해가 유일"이 완성돼요.

9.5 크라머 공식

  • x_k = det A_k / det A (k = 1, …, n). A_k는 A의 k번째 열을 B로 바꾼 행렬이에요.
  • 왜 k번째 열인가: X = adj A·B / det A에서 x_k의 분자는 C₁k·b₁ + C₂k·b₂ + …인데, 이 여인수들은 모두 k열을 지우고 만든 것이라 그 빈자리에 B가 들어간 행렬의 행렬식이 돼요.
  • 예: 2x + y = 5, x − y = 1이면 det A = −3, det A₁ = |5 1; 1 −1| = −6, det A₂ = |2 5; 1 1| = −3이라 x = 2, y = 1이에요.
  • det A를 먼저 구하고, 0이 아니면 열을 하나씩 바꿔 가며 행렬식을 n개 더 구하면 끝이에요. det A = 0이면 쓸 수 없어요.

10장 · 무한급수

무한급수의 합을 정확히 구하는 것은 대부분 불가능해요. 그래서 질문을 "합이 얼마냐"에서 "유한한 값으로 수렴하긴 하냐"로 바꾸고, 그것을 판정하는 도구들을 배워요.

10.1 수열의 수렴

  • 수열은 정의역이 자연수인 함수예요. 임의의 ε > 0에 대해 n > N이면 |aₙ − L| < ε이 되는 N이 있을 때 {aₙ}이 L로 수렴한다고 해요. N은 ε에 따라 달라져요.
  • 예: aₙ = 1/n이면 N > 1/ε로 잡으면 돼요. ε = 10⁻³이면 N = 1001처럼요.
  • 극한의 사칙연산(정리 10.1)과 조임 정리(정리 10.2, aₙ ≤ bₙ ≤ cₙ이고 양쪽이 L로 가면 bₙ도 L)를 써요. |bₙ| ≤ cₙ → 0이면 bₙ → 0이에요.

10.2 무한급수

  • 부분합 Sₙ = a₁ + … + aₙ의 수열이 L로 수렴하면 급수가 L로 수렴한다고 해요.
  • 등비급수 Σ arⁿ⁻¹: |r| < 1이면 a/(1 − r)로 수렴, |r| ≥ 1이면 발산.
  • 망원급수: 부분합에서 가운데 항이 모두 지워지는 꼴. Σ 1/(n(n + 1)) = Σ (1/n − 1/(n + 1)) = 1.
  • 조화급수 Σ 1/n은 발산해요. 1 + ½ + (⅓ + ¼) + (⅕ + … + ⅛) + …에서 괄호마다 ½ 이상이라 끝없이 커져요. 일반항이 0으로 가는데도 발산하는 대표 예예요.
  • 발산판정법: lim aₙ ≠ 0이면 발산. 거꾸로 lim aₙ = 0이라고 수렴하는 것은 아니에요(조화급수). 이 판정법으로는 발산만 결론 낼 수 있어요.

10.3 적분판정법과 p급수

  • 각 항 aₙ을 폭 1, 높이 aₙ인 직사각형으로 보면, f가 감소함수일 때 직사각형들이 곡선 아래에 들어가요. 양수를 더하니 부분합은 계속 커지는데 넘지 못하는 천장(적분)이 있으면 수렴해요.
  • 정리 10.6 (적분판정법): f가 x ≥ 1에서 연속 · 양 · 감소이고 aₙ = f(n)이면, ∫₁^∞ f(x) dx가 수렴하면 Σ aₙ도 수렴하고, 발산하면 Σ aₙ도 발산해요.
  • 세 조건 중 하나라도 깨지면 못 써요. 처음 몇 항에서만 깨지는 건 괜찮아요(감소하기 시작하는 곳부터 적분). 적분값은 천장일 뿐 급수의 합이 아니에요.

p급수: Σ 1/nᵖ는 p > 1이면 수렴, p ≤ 1이면 발산

  • [1] 조건 확인: p > 0이라 하고 f(x) = 1/xᵖ로 두면 aₙ = f(n)이에요. x ≥ 1에서 ① xᵖ ≠ 0이라 연속, ② xᵖ > 0이라 양수, ③ f′(x) = −p·x^(−p−1) < 0이라 감소. 그래서 적분판정법을 쓸 수 있어요.
  • [2] p ≠ 1: ∫₁^b x^(−p) dx = (b^(1−p) − 1)/(1 − p). p > 1이면 1 − p < 0이라 b^(1−p) → 0, 적분 = 1/(p − 1) < ∞ → 수렴. 0 < p < 1이면 b^(1−p) → ∞ → 발산.
  • [3] p = 1: [2]의 분모 1 − p가 0이 되어 따로 계산해요. ∫₁^A dx/x = ln A → ∞라서 조화급수는 발산해요.
  • [4] p ≤ 0: f가 감소함수가 아니라 적분판정법을 못 써요. p = 0이면 aₙ = 1, p < 0이면 aₙ → ∞라서 발산판정법으로 발산.
  • [5] 결론: p > 1이면 수렴, p ≤ 1이면 발산. 조건 확인과 "p = 1을 왜 따로 다루는지"를 빠뜨리지 않는 게 중요해요.

10.4 비교판정법

  • 비교판정법: 0 ≤ aₙ ≤ bₙ일 때, Σ bₙ이 수렴하면 Σ aₙ도 수렴하고, Σ aₙ이 발산하면 Σ bₙ도 발산해요.
  • 극한비교판정법: lim aₙ/bₙ = c이고 0 < c < ∞면 두 급수는 함께 수렴하거나 함께 발산해요.
  • 비교 대상은 거의 항상 p급수나 등비급수예요. 분수식은 최고차항만 남겨 비교해요: Σ (n + 100)/(n³ + 2)는 n/n³ = 1/n²와 비교 → p = 2 > 1이라 수렴.

10.5 교대급수와 절대수렴

  • 정리 10.11 (교대급수판정법): Σ (−1)ⁿ⁺¹aₙ에서 ① aₙ > 0, ② aₙ ≥ aₙ₊₁, ③ lim aₙ = 0이면 수렴해요.
  • Σ |aₙ|이 수렴하면 절대수렴이에요. 정리 10.12: 절대수렴하면 수렴해요(역은 거짓). 수렴하지만 절대수렴하지 않으면 조건수렴이에요. 예: 1 − ½ + ⅓ − ¼ + …
  • 적분·비교·비·근 판정법은 모두 양항급수용이라, 부호가 섞인 급수는 절댓값을 씌워 판정한 뒤 정리 10.12로 원래 급수에 결과를 돌려줘요.
  • 교대 p급수 Σ (−1)ⁿ⁺¹/nᵖ (p > 0)는 항상 수렴하고, p > 1이면 절대수렴, 0 < p ≤ 1이면 조건수렴이에요.

10.7 Taylor 급수

  • 정리 10.15 (Taylor 공식): f(x) = Pₙ(x) + Rₙ(x), Rₙ(x) = f⁽ⁿ⁺¹⁾(ξ)/(n + 1)! · (x − c)ⁿ⁺¹. ξ는 c와 x 사이의 어떤 수로, 존재만 알고 위치는 몰라요. 그래서 범위로 가둬 부등식으로 다뤄요.
  • 정리 10.16: lim Rₙ(x) = 0이면 Taylor 급수가 f(x)로 수렴해요. "급수가 수렴한다"와 "하필 f(x)로 수렴한다"는 다른 주장이라 이 조건이 필요해요.
  • eˣ의 Maclaurin 급수가 모든 x에서 eˣ로 수렴함: [1] 모든 k에 대해 f⁽ᵏ⁾(x) = eˣ라서 c = 0에서 Taylor 공식을 쓸 수 있어요. [2] eˣ = 1 + x + x²/2! + … + xⁿ/n! + Rₙ, Rₙ = e^ξ·xⁿ⁺¹/(n + 1)!. [3] eᵗ는 증가함수라 x > 0이면 e^ξ < eˣ, x < 0이면 e^ξ < 1, x = 0이면 Rₙ = 0. [4] 어느 경우든 n과 무관한 상수 × |x|ⁿ⁺¹/(n + 1)!이고 xⁿ/n! → 0(표 10.1)이라 Rₙ → 0. [5] 정리 10.16에 의해 eˣ = Σ xⁿ/n!.
  • cos x도 같은 구조인데, |cos⁽ⁿ⁾(x)| ≤ 1이라 경우를 나눌 필요도 없어요.

11장 · 극좌표

11.1 극좌표

  • 원점 O를 극, 양의 x축을 극축, r을 반지름, θ를 편각이라고 해요. θ는 반시계방향이 양이에요.
  • 한 점이 무수히 많은 좌표를 가져요: (r, θ) = (r, θ + 2nπ) = (−r, θ + π + 2nπ). (−r, θ)는 (r, θ)를 원점 기준으로 π만큼 돌린 점이라 (−2, π/6) = (2, 7π/6)이에요.
  • 변환: x = r cos θ, y = r sin θ, r² = x² + y², tan θ = y/x. tan의 주기가 π라 θ 후보가 두 개 나오니 사분면을 보고 골라요. (−1, −1)은 r = √2, θ = 5π/4예요.
  • 극방정식을 직교좌표로 바꿀 때는 양변에 r을 곱해 r², r cos θ, r sin θ를 만들어요: r = 4cos θ → r² = 4r cos θ → x² + y² = 4x → (x − 2)² + y² = 4.

11.2 극방정식의 그래프

  • 1단계 대칭성: 아래를 대입해도 식이 그대로면 대칭이에요. 둘 중 하나만 맞아도 돼요. x축(극축): (r, −θ) 또는 (−r, π − θ). y축(θ = π/2): (r, π − θ) 또는 (−r, −θ). 원점: (−r, θ) 또는 (r, π + θ).
  • 2단계 특수각 표: θ = 0, π/6, π/4, π/3, π/2, 2π/3, 3π/4, 5π/6, π에서 r을 계산해요.
  • 3단계 점 찍고 잇기: θ가 커지는 순서로 이어요. r < 0이면 반대쪽(θ + π 방향)에 찍고, 마지막에 대칭으로 나머지를 복사해요.
  • 장미 r = sin nθ, cos nθ: n이 홀수면 꽃잎 n개, 짝수면 2n개예요. 홀수면 마주 보는 위치의 r 부호가 반대라 꽃잎이 겹치기 때문이에요.
  • 리마송 r = a ± b cos θ (또는 sin θ): r의 최솟값이 a − b라서 a/b 하나로 모양이 정해져요. a < b면 r이 음수인 구간이 반대쪽에 찍혀 안쪽 고리, a = b면 한 번 0이 되어 뾰족한 심장형, 1 < a/b < 2면 오목, a/b ≥ 2면 볼록이에요. 개형은 a − b와 a + b만 먼저 계산하면 거의 끝나요.
  • 리본형 r² = a cos θ, a cos 2θ: 우변이 음수인 구간에는 그래프가 없어요. r = ±√f라서 x축·y축·원점 모두 대칭이에요. 나선 r = aθ는 θ가 커질수록 r도 커져요.

11.3 극좌표에서의 넓이

  • A = ∫ ½ r² dθ (θ: α → β). 두 곡선 사이는 A = ∫ ½ (r_바깥² − r_안쪽²) dθ.
  • ½이 붙는 이유: 반지름 r, 중심각 Δθ인 부채꼴의 넓이가 πr²·(Δθ/2π) = ½r²Δθ이기 때문이에요. 직교좌표에서 직사각형으로 쪼개던 것을 부채꼴로 쪼갤 뿐이에요.
  • 어려운 건 적분 구간이에요. 곡선 전체는 한 바퀴(보통 0 ~ 2π, 장미는 겹침 주의), 잎이나 고리 하나는 r = 0이 되는 이웃한 두 θ 사이(r = sin 3θ의 잎 하나: 0 ~ π/3, r = 2cos θ + 1의 작은 고리: 2π/3 ~ 4π/3), 두 곡선 사이는 교점의 θ가 양 끝이에요. x축 대칭이면 위 절반만 적분하고 2배 해요.
  • r²를 전개하면 거의 항상 cos²θ나 sin²θ가 나와요. 반각공식 cos²θ = (1 + cos 2θ)/2, sin²θ = (1 − cos 2θ)/2로 바꿔야 적분돼요.
  • 예: r = 2(1 + cos θ) 전체는 ½ ∫ 4(1 + cos θ)² dθ (0 → 2π) = 2(2π + π) = 6π. 원 r = 1 안쪽이면서 심장형 r = 1 − cos θ 바깥은 cos θ > 0인 −π/2 ~ π/2에서 ½∫(1 − (1 − cos θ)²) dθ = 2 − π/4.

자주 틀리는 지점

  • (A + B)²를 A² + 2AB + B²로 쓰기 → AB + BA가 맞아요.
  • 행축소에서 도착하는 행의 계수가 1이 아닌데 det가 그대로라고 착각하기. det(kA)를 k·det A로 쓰기 → kⁿ·det A.
  • 적분판정법을 쓰면서 감소함수인지 확인하지 않기. 적분값을 급수의 합이라고 쓰기.
  • 비판정법·근판정법에서 L = 1인데 결론 내기 → 판정 불가예요.
  • 잎 하나의 넓이에서 구간을 0 ~ 2π로 잡기. cos²θ를 반각공식 없이 적분하려다 막히기. r < 0인 점을 같은 방향에 찍기.
